# Análisis Estadístico II (602) — Trabajo Práctico · 2025

**Universidad de Buenos Aires · Facultad de Ciencias Económicas**

Este trabajo examina el crecimiento real anual del PIB per cápita de Dinamarca, Noruega y Finlandia a partir de información del Banco Mundial disponible en junio de 2025.

El estudio comprende estadísticas descriptivas, intervalos de confianza al 95 %, contrastes de hipótesis para medias y proporciones, ANOVA, bondad de ajuste y regresión lineal simple. Se discuten los supuestos estadísticos y la dependencia temporal presente en las observaciones anuales.

**Documento principal:** [`TP_Analisis_Estadistico_II_UBA_2025.ipynb`](./TP_Analisis_Estadistico_II_UBA_2025.ipynb).

**Fuente:** Banco Mundial, *World Development Indicators Database Archives*, edición del 5 de junio de 2025 (serie de crecimiento real: `NY.GDP.PCAP.KD.ZG`). Se analiza el período 1961–2024 según disponibilidad.

**Materia:** [Análisis Estadístico II (602), UBA-FCE](https://mi.econ.uba.ar/programas/?mate=602).

*Los resultados numéricos del notebook se calculan al ejecutar sus celdas sobre la edición histórica indicada.*
